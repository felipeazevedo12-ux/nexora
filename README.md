# Nexora

Monorepo para uma plataforma de comunicação com frontend Next.js, API principal, mensageria realtime, PostgreSQL, Redis e LiveKit.

## Estrutura

- `apps/nexora-web`: frontend
- `apps/nexora-core`: API principal
- `apps/nexora-realtime`: WebSocket/realtime
- `packages/types`: tipos compartilhados
- `packages/desktop-native`: módulos nativos futuros
- `infra`: infraestrutura local
